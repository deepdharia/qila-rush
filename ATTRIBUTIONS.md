## Flags — verify before using

1. **Quaternius is NO LONGER CC0.** Licence changed 28 Aug 2026 to the "Quaternius Asset License v1.0": free commercial use, no credit, but **no reselling/redistribution of the assets as assets**. Older CC0 claims are out of date. Read the current licence on each pack page before use. https://quaternius.com
2. **OpenGameArt's copy of the Avramania collection is unavailable** ("files currently unavailable due to potential licensing issues") — use the itch.io link above.
3. **Per-file licences vary** on Freesound, Sketchfab and Poly Pizza — check every file (CC0 or CC-BY only; never CC-BY-NC).
4. **Incompetech credit** must stay visible in the game while any of its tracks ship (the menu credit line covers this).
